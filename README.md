# 星星接接乐 · Star Catch

一款打开就能玩的 H5 小游戏：移动月亮小船接住掉落的星星，躲开流星。3 条命，难度递增，一局不到一分钟。

## 在线试玩

**https://guwen123456.github.io/star-catch-game/**

手机/电脑浏览器打开即玩。点「开始游戏」后有背景音乐（纯代码合成，无音频文件）。

## 玩法

- ⭐ 普通星星 +10 分　🌟 金色星星 +30 分
- ☄️ 流星别接；漏掉星星也会扣命；共 3 条命
- 操作：手指拖动 / 鼠标移动 / ← → 方向键；空格开始；右上角按钮或 M 键静音
- 连击计数、难度自动递增、本地最高分纪录
- 纯离线单机：不联网、不注册、不收集任何个人信息、无内购

## 技术

- 单文件 `index.html`（HTML + CSS + JS + Canvas + WebAudio），零依赖、零构建，双击即可运行
- 背景音乐与音效全部由 WebAudio 实时合成（100 BPM，C–F–C–G 五声音阶循环），无任何外部素材，无版权风险
- 竖屏自适应（桌面端居中限宽 480px），支持触屏/鼠标/键盘
